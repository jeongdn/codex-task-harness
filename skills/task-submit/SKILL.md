# 제출 준비

1. 제출 문서 파일명을 정한다. 과제 안내에 정해진 이름이 있으면 그것을 쓴다. 루트의 README.md가 과제 설명이면 덮어쓰지 말고 사용자에게 파일명을 묻는다.
2. 이 스킬의 `assets/SUBMISSION.md` 골격을 채운다.
   실행 방법(명령 한 줄), 한 줄 소개, 담당자 요구 대응표(M·R·C·D → 반영 위치·확인 방법), 판단 기준과 기준값, 테스트 방법과 결과, 가정과 한계, 다음에 할 일, AI 활용 기록(받아들인 제안·사용자가 고른 안과 고친 제안, DESIGN.md·DECISIONS.md 근거, 이유는 사용자가 한 말 그대로).
3. 실제로 확인한 것만 쓴다. 확인하지 못한 것은 '확인하지 못함'이라고 쓴다.
4. 제출 문서만 `git add <파일>`로 올려 커밋한다: `git commit -m "[제출] 제출 문서 / 실행법과 요구 대응 정리"`
5. 채팅에 후속 질문 대비 메모를 20줄 이내로 보여 준다. 파일로 만들지 않는다.
   - 핵심 함수 3개: 무엇을 하고 왜 그렇게 했나
   - 기준값과 그 근거(담당자 말 또는 데이터)
   - 깨질 수 있는 곳 3개와 그때 일어나는 일
   - 다음에 검증할 것 2개
   - AI 제안 중 고친 것 1~2개와 이유
