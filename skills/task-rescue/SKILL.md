# 비상 마감

목표: 남은 시간 안에 "돌아가는 것 + 정직한 설명"을 제출한다. 새 기능은 만들지 않는다.

1. 남은 시간을 확인한다. 모르면 사용자에게 묻는다.
2. 지금 상태를 판정한다: 전체 테스트와 README의 실행 명령을 한 번씩 돌린다.
3. 깨져 있으면 `git log --oneline`에서 마지막으로 테스트가 통과한 커밋을 찾고, 그 뒤 바뀐 파일을 보여 준다.
   - 되돌릴 범위(전체 / 파일 몇 개)는 사용자에게 묻고, 답을 받은 뒤에만 실행한다.
   - 되돌리기 전에 지금 상태를 `git stash` 또는 `[임시] 되돌리기 전 상태` 커밋으로 남긴다.
4. PLAN.md의 '시간이 모자라면 버릴 순서'대로 남은 단계를 자른다. 성공 기준(M)과 금지(D)는 남긴다. 버린 것을 표로 보여 준다.
5. 남은 시간이 20분 이상이면 성공 기준 하나만 마무리한다. 그보다 적으면 코드는 멈춘다.
6. 제출 문서를 쓴다($task-submit과 같은 골격). 못 한 것은 "하지 못함: 이유 / 다음에 할 방법"으로 정직하게 적는다.
7. 커밋하고, 채팅에 "제출 전 30초 점검"을 보여 준다: 실행 명령 한 줄, 성공 기준 결과, 버린 것, 확인 문제에서 말할 핵심 3가지.
