# 인터뷰 정리와 합의문

입력: 사용자가 붙여 준 담당자 대화, 또는 INTERVIEW.md에 적힌 질문과 답.

1. 대화를 INTERVIEW.md 표에 한 행씩 옮긴다. 이미 행이 있으면 그대로 두고 다음 번호로 덧붙인다. 답은 줄이지 말고 담당자 표현을 살린다. 반영 위치 칸에는 AGREEMENT.md의 항목 번호(R1, M1 등)를 적는다.
2. 답마다 분류를 붙인다: R 요구, C 제약(환경·보안·시간), D 하면 안 되는 것, M 숫자로 확인할 성공 기준, B 배경.
3. AGREEMENT.md를 채운다. 항목마다 근거가 된 INTERVIEW.md 번호를 괄호로 붙인다.
   - 담당자가 말하지 않은 것은 R·C·D·M에 넣지 않고 '가정·미확인'에 적는다.
   - 성공 기준이 숫자로 정해지지 않았으면 '미확인'으로 두고 물어볼 질문을 만든다.
4. 아직 비어 있는 축(사용 환경, 보안, 역할별 권한, 데이터의 주인과 개인정보 범위, 하면 안 되는 것, 성공 기준 숫자, 데이터 신뢰도)에 대해 담당자에게 물을 질문을 최대 3개 만든다.
   - 답에 따라 결과물이 달라지는 질문만 만든다. 이미 답을 받은 내용은 다시 묻지 않는다.
   - 데이터에 실제로 없는 경우(0건인 예외, 생길지 모르는 형식)는 묻지 말고 '가정·미확인'에 적는다.
   - 다음에 쓸 때의 모습(다음 주 파일, 새 문서가 들어오면 어떻게 돌리는지)이 비어 있으면 그것을 먼저 묻는다.
5. 담당자에게 보낼 확인 메시지를 만든다: 합의 내용 5~8줄 요약 + "빠지거나 틀린 게 있으면 알려 주세요." 짧고 쉬운 말로. 사용자가 담당자 확인을 받았다고 하면 AGREEMENT.md의 '담당자 확인'에 체크한다.
6. 채팅에는 확인 메시지와 추가 질문 3개만 보여 준다. 코드는 쓰지 않는다.
