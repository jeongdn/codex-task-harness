# 검증

1. 전체 테스트를 실행하고 명령과 결과(통과·실패 수)를 VERIFY.md에 적는다.
2. 성공 기준(M)은 실제 데이터로 직접 실행해 숫자를 확인한다. 테스트 통과만 믿지 않는다.
3. AGREEMENT.md의 항목마다 판정한다: 충족 / 부분 / 미충족 / 확인 불가. 근거로 파일·함수 이름이나 명령 출력을 붙인다.
4. 경계 입력을 3가지 이상 시험한다: 빈 값, 형식이 다른 값, 중복, 아주 큰 값, 없는 키 등. 결과를 적고 추가할 테스트를 제안한다.
5. 금지(D)와 제약(C) 위반을 따로 확인한다: 원본 파일 수정, 외부 호출, 설치가 필요한 패키지, 하지 말라고 한 기능.
6. 위험과 한계, 다음에 검증할 것을 적는다.
7. 코드는 고치지 않는다. 고칠 것은 우선순위와 예상 시간을 붙여 보고하고 사용자 승인을 기다린다.
