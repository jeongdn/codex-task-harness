# 과제 파악

목표: 10분 안에 무엇을 모르는지 드러낸다. 구현 코드는 쓰지 않고, 원본 파일은 수정하지 않는다.

1. 과제 설명(README 등)을 읽고 NOTES.md에 과제 한 줄 요약과 제출물을 적는다.
2. 데이터는 통째로 읽지 말고 이 스킬의 스크립트로 요약한다. 폴더를 넣으면 안의 CSV·엑셀·문서를 모두 본다.
   `python3 ~/.agents/skills/task-intake/scripts/profile_data.py <파일 또는 폴더> ...`
3. 요약에서 다음을 찾아 NOTES.md 표에 적는다.
   - 행 수, 열 이름, 파일마다 다른 열 이름
   - 빈 값, N/A 같은 결측 표기, 완전히 같은 중복 행
   - 표기만 다른 같은 값(대소문자, 하이픈, 공백)
   - 섞여 있는 날짜·시각 형식, 숫자 열의 이상한 값
   - 문서라면 버전·개정일·상태(정식/초안) 같은 메타 정보
4. 모르는 것과 가정을 나눠 적는다. 담당자가 말하지 않은 판단 기준은 모두 가정이다.
5. 담당자에게 물을 질문을 중요한 순서로 8~12개 적는다. 아래 축을 한 번씩은 덮는다.
   지금 하는 방식 / 지난 사고·예외 / 쓰는 사람·시점·결과 형태 / 믿으면 안 되는 데이터 / 사용 환경·보안 / 하면 안 되는 것 / 숫자로 된 성공 기준
   질문은 담당자가 바로 답할 수 있는 구체적인 문장으로 쓴다. "요구사항을 다 알려 주세요" 같은 질문은 쓰지 않는다.
6. 채팅에는 NOTES.md에 적은 것과 질문 상위 5개만 짧게 보고한다.
